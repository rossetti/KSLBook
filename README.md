# Simulation Modeling using the Kotlin Simulation Library (KSL)

The published site of *Simulation Modeling using the Kotlin Simulation Library
(KSL)* by Manuel D. Rossetti, an introductory textbook on discrete-event and Monte
Carlo simulation modeling.

**Read the book: <https://rossetti.github.io/KSLBook/>**

## What is on the site

- **The book**, 11 chapters and 6 appendices, with **Download PDF** and **EPUB**
  buttons in the sidebar.
- **Lecture Slides**: reveal.js decks for each chapter.
- **Quiz Study Guides**: 11 decks, for chapters 1 to 9 and the appendices on
  random variates and distribution fitting, as HTML and as PDF.
- **Class Activities**: in-class activities in six series, from modeling
  randomness to the process view and the KSL applications, with their starter code
  and data, and a guide to installing the KSL applications.

Each is linked from the book's sidebar.

## The Kotlin Simulation Library

The library, and the example code the book refers to (under `KSLExamples/`), are in
the [KSL repository](https://github.com/rossetti/KSL).

## About this repository

This repository only serves the site: GitHub Pages publishes the `docs/` folder.
Everything in `docs/` is generated from the book's source, which is kept in a
separate repository, and is replaced each time the book is published, so changes
made to `docs/` directly would be lost.

To report an error in the book, its slides, or its activities, please
[open an issue](https://github.com/rossetti/KSLBook/issues) here.
